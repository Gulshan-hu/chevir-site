# Chevir

Azərbaycan jest dili (AZİD) ilə danışıq Azərbaycan dili arasında real vaxtda ikitərəfli tərcümə quran landing page.

## Texnologiyalar

- [Vite](https://vitejs.dev/)
- Vanilla JavaScript
- [GSAP](https://gsap.com/) (ScrollTrigger)
- [Lenis](https://lenis.darkroom.engineering/) (hamar scroll)
- [Three.js](https://threejs.org/)

## Lokal işə salma

```bash
npm install
npm run dev
```
